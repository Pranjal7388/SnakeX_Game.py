# SnakeX_Game.py   SnakeX is a classic Snake game built using Python and Pygame. Control the snake, collect food, grow longer, and try to achieve the highest score possible while avoiding collisions with walls and yourself.

**Features**
Classic Snake gameplay
Score tracking
High score saving
Game Over screen
Restart option

**Controls**
Arrow Keys → Move the snake
C → Restart after Game Over
Q → Quit the game
ESC → Exit the game
